# SHADOW CITY — Anime Legends

An original, offline-first, mobile 3D open-world action prototype.

## Target
- Android phones first; offline single-player gameplay.
- Original characters, city layout, UI, names, and visual assets (not copied from GTA or other franchises).
- Premium violet/cyan neon palette with an anime-inspired third-person hero.

## Prototype milestones
1. **Playable core:** third-person movement, camera follow, jump/dash, one melee/energy attack, health and XP.
2. **Small city block:** roads, sidewalks, buildings, lights, collision boundaries, one drivable vehicle only after walking controls work.
3. **Mission loop:** one offline mission, enemies, reward, XP/level-up screen, pause/restart.
4. **Android build:** touch joystick/buttons, quality settings, package APK, install-test and fix reported device issues.
5. **Expansion:** more city districts, vehicles, missions, NPCs, character skins and save progress.

## Important technical rule
A full GTA-sized open world is not a realistic first build. Start with a compact, real playable 3D vertical slice and expand it after testing on the target phone. Do not label mockups or web-only previews as a finished native 3D APK.
